# Reporte-Ciudadano---Reto-2-Ciudad-que-responde-
Plataforma web de respuesta ciudadana con IA integrada para categorizar reportes vía foto/ubicación, automatizar la atención a trámites y ofrecer mapas de calor para la toma de decisiones municipales.

Al Ciudadano (Cualquier nivel digital):   
  Problema: Proceso frustrante para reportar fallas (baches, luminarias, fugas) y trámites gubernamentales redactados en lenguaje burocrático incomprensible.   
  Solución: Un canal web exprés donde reporta con foto y geolocalización en segundos, recibe estatus transparente de su folio y        consulta trámites traducidos a lenguaje claro por un asistente de IA.   
Al Gobierno / Servidores Públicos (Obras Públicas y Atención Ciudadana):   
  Problema: Desorden masivo de folios, reportes duplicados y falta de criterio objetivo para saber qué atender primero.   
  Solución: Panel administrativo centralizado que usa IA para categorizar y priorizar automáticamente la urgencia de los reportes,     desplegando un mapa de calor para optimizar las cuadrillas en campo.
